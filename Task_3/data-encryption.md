# Анализ рисков в зависимости от класса конфиденциальности данных

| Класс              | 	Законодательство	                  | Последствия утечки                                          |
|:-------------------|:------------------------------------|:------------------------------------------------------------|
| Класс_1 (PHI)	     | 323-ФЗ (врачебная тайна), 152-ФЗ    | 	Уголовная ответственность (ст. 137 УК РФ), потеря лицензии |
| Класс_2 (PII+PHI)  | 	152-ФЗ (ПДн + спец. категории)     | 	Штрафы (ст. 13.11 КоАП РФ)                 |
| Класс_3 (PII)      | 	152-ФЗ (ПДн)                       | 	Штрафы, репутационные потери                               |
| Класс_4 (Finance)	 | 115-ФЗ, 152-ФЗ	                     | Блокировка операций, мошенничество, штрафы, репутационные потери                |
| Класс_5 (Внутренние, не-ПДн)	        | Регулируется внутренними политиками |	Репутационные потери |

| Данные                                   | At Rest                            | In Transit | Контроль                                       |
|:-----------------------------------------|:-----------------------------------|:-----------|:-----------------------------------------------|
| Диагноз, заключение, анамнез (Класс_1)   | 	LUKS, pgcrypto (AES-256)          | 	TLS 1.3   | 	Аудит доступа, ABAC                           |
| Результаты анализов (PDF) (Класс_1)      | 	MinIO SSE-S3, LUKS                | 	TLS 1.3   | 	API-шлюз, ABAC, аудит доступа                 |
| ФИО + данные о посещении врача (Класс_2) | 	LUKS, pgcrypto                    | 	TLS 1.3   | 	ABAC, аудит доступа                           |
| ФИО + Контактные данные (Класс_3)        | 	LUKS, pgcrypto                    | 	TLS 1.3   | 	ABAC, аудит доступа                            |
| Номер карты, сумма платежа (Класс_4)     | Не хранить. Токенизация, pgcrypto	 | mTLS, VPN  | 	Отдельный сервис платежей, аудит              |
| Обезличенные данные для BI (Класс_5)     | 	LUKS, обезличивание перед записью | 	TLS 1.3   | 	RBAC                                          |
| Логи доступа (Класс_5)                   | 	LUKS, обезличивание перед записью | 	TLS 1.3   | 	Wazuh SIEM (Open Source), мониторинг аномалий |
| ПК сотрудников: трафик, кеш ОС           | LUKS \ BitLocker \ DLP             | VPN, TLS 1.3      | ABAC, аудит доступа                            |
