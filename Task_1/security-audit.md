# Проблемные зоны безопасности данных
## Компания «Медикаменте» (состояние As-Is)
### Дата: апрель 2026

## 1. Классы конфиденциальности данных 

| Класс | Класс (PHI/PII) | Название     | Примеры                                   |
| :------ | :---- |:-----------------------------|:------------------------------------------|
| Класс_1 | PHI | Медицинская тайна            | Диагнозы, заключения, результаты анализов |

## 2. Проблемы по DFD

- 1.3: Журнал без аудита [Класс_2]
- 1.4: Врач видит всех пациентов [Класс_2]
- 1.5: Папки с ФИО в названии [Класс_2]
- 1.6: Нет RBAC между сотрудниками [Класс_2-3]
- 1.7: Результаты приема хранятся на общем диске [Класс_1]

### DFD 2. Учёт платежей
- 2.1: Двойной учёт (Excel + 1С) [Класс_4]
- 2.2: Excel-журнал в открытом доступе [Класс_4]
- 2.3: ККМ -> 1С: OLE/TCP без шифрования [Класс_4]
- 2.4: Нет аудита 1С [Класс_4]

### DFD 3. Передача анализов в лабораторию
- 3.1: Передача реестра по email [Класс_2]
- 3.2: Файл учета анализов без RBAC [Класс_2]
- 3.3: Ручная выгрузка (нет API) [Класс_2]
- 3.4: Результаты анализов без RBAC [Класс_1]

### DFD 4. Хранение и доступ к медицинским картам
- 4.1: Общий доступ к файловому серверу [Класс_1-2]
- 4.2: Нет шифрования при хранении [Класс_1-2]
- 4.3: Нет аудита доступа [Класс_1-2]
- 4.4: Нет политики удаления [Класс_1-2]
- 4.5: Имена папок с ФИО [Класс_2]

### DFD 5. Доступ к файловому серверу (AD, LDAP)
- 5.1: Аутентификация есть, авторизации нет (нет RBAC) [Класс_1-4]
- 5.3: Администратор может всё без аудита [Класс_1-4]

### DFD 6. Передача данных в 1С (кадры, зарплаты)
- 6.1: ПДн сотрудников в 1С без шифрования [Класс_3]
- 6.2: Зарплаты в 1С без разграничения [Класс_4]
- 6.3: Нет аудита изменений в 1С [Класс_3-4]
- 6.4: Передача в ФНС без контроля [Класс_3-4]

## 3. Системные проблемы (сквозные)
- S1: Нет RBAC/ABAC, нарушен принцип наименьших привилегий
- S2: Нет отслеживания происхождения данных
- S3: Нет аудита и мониторинга
- S4: Нет шифрования (at rest / in transit)
- S5: Нет ответственного за ПДн
- S6: Нет политики уничтожения данных
- S7: Нет плана реагирования на утечки
- S8: Нет отдельных согласий на обработку ПДн

## 4. Нормативные нарушения
- 152-ФЗ: ст. 5, 6, 9, 14, 16, 18.1, 19, 21, 22
- 323-ФЗ: ст. 13 (врачебная тайна)
- 115-ФЗ: идентификация, хранение 5 лет, контроль операций
