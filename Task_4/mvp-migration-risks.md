# Отчёт: узкие места миграции на MVP (портал записи)

## 1. Инфраструктура

| Проблема                                  | Риск для MVP                                                                                      | Рекомендация                                        | Приоритет |
|-------------------------------------------|---------------------------------------------------------------------------------------------------|-----------------------------------------------------|-----------|
| Проблемы с отказоустойчивостью            | Сбой облака или сервера - портал недоступен                                                       | Развернуть MVP в российском облаке с SLA 99.9%      | **P0**    |
| Нехватка ресурсов на существующем сервере | Старое железо не тянет новую БД + портал                                                          | Использовать облачные managed-сервисы (БД, compute) | **P0**    |
| Потеря данных после запуска портала       | Исторические данные есть в Excel, новые данные могут быть потеряны из-за инфраструктурных проблем | Настроить регулярные бекапы БД                      | **P1**    |

---

## 2. Программное обеспечение

| Проблема                                          | Риск для MVP                              | Рекомендация                                                           | Приоритет |
|---------------------------------------------------|-------------------------------------------|------------------------------------------------------------------------|-----------|
| Плохо протестировано (включая RBAC)               | Ошибки разграничения доступа, сбои логики | Функциональное + нагрузочное тестирование; отдельный тест-кейс на RBAC | **P0**    |
| Новое ПО не выполняет требования законодательства | Нарушение 152-ФЗ (согласия, утечки)       | Юридическая проверка MVP (согласия на ПД, хранение, уведомления)       | **P0**    |
| Тестирование на прод-данных                       | Утечка конфиденциальных данных            | Подготовка маскированных данных для тестирования                       | **P0**    |

---

## 3. Интеграция

| Проблема | Риск для MVP | Рекомендация                                                                                            | Приоритет |
|----------|--------------|---------------------------------------------------------------------------------------------------------|------------|
| Нет автоматической интеграции со старой системой | Данные о врачах, расписании не синхронизированы | Запретить запись в Excel после запуска портала; реализовать (полу-)автоматическую синхронизацию с Excel | **P0** |
| Проблемы с отправкой напоминаний | Пациенты не приходят, врачи простаивают | Использовать нескольких провайдеров (SMS + email) с fallback                                            | **P1** |

---

## 4. Данные

| Проблема | Риск для MVP | Рекомендация | Приоритет |
|----------|--------------|--------------|------------|
| Данные плохо подготовлены к миграции | Ошибки в списке врачей, слотов, контактах | Очистить и провалидировать контакты (телефоны, email) перед миграцией | **P0** |
| Утечка данных в процессе миграции | Нарушение 152-ФЗ, репутация | Использовать маскирование данных в тестовой среде | **P0** |
| Пациент увидел чужие записи | Нарушение врачебной тайны, штрафы | Настроить аудит доступа к записям; отдельный тест RBAC | **P0** |

---

## 5. Персонал

| Проблема                                      | Риск для MVP                                                                   | Рекомендация                                                  | Приоритет |
|-----------------------------------------------|--------------------------------------------------------------------------------|---------------------------------------------------------------|-----------|
| Недостаточность штата, нет владельца миграции | Не успевают разрабатывать, тестировать, поддерживать; размытая ответственность | Организовать найм разработчиков, devops, ПМ                   | **P0**    |
| Нет экспертизы по защите ПД                   | Ошибки в правах, логировании, согласиях                                        | Привлечь внешнего консультанта по 152-ФЗ для разовой проверки | **P1**    |
| Новая система для сотрудников (непривычка)    | Снижение скорости работы персонала с клиентами                                 | Провести обучение                                             | **P1**    |

---

## 6. Процессы

| Проблема | Риск для MVP | Рекомендация                                                                                                        | Приоритет |
|----------|--------------|---------------------------------------------------------------------------------------------------------------------|-----------|
| Риск двойной записи персоналом | Конфликт слотов (Excel vs портал) | Запретить запись в Excel после запуска портала                                                                      | **P1**    |
| Не проработана стратегия миграции / отката | При сбое MVP нет понятного пути возврата к Excel | Разработать пошаговый план cutover (пилот -> полный запуск) + план отката (1 час на возврат)                        | **P0**    |
| Проблемы с поддержкой пользователей | Пациенты и сотрудники не знают, куда обращаться при ошибках | Назначить IT-специалиста ответственным за поддержку в первые 2 недели; сделать форму обратной связи / FAQ в портале | **P1**    |
